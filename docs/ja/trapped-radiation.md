# 捕捉放射線（AP-8 と AE-8）

解析 `orbit.trapped_flux` は、地球の放射線帯に捕捉された陽子と電子の、軌道平均とピークの積分フラックスと、ミッション中のフルエンスを
NASA の AP-8 と AE-8 モデルから求めます。全線量の見積もりのうち、環境にあたる部分です。アルミニウム遮蔽の内側の線量への換算は解析 `orbit.trapped_dose` が行います（[遮蔽の内側の線量](#遮蔽の内側の線量orbittrapped_dose)を参照）。
`orbit.total_dose` は、レッグに専用の環境表がないときにこれを使います（[#470](https://github.com/akira-nkjm/iwafune/issues/470)）。

## 何を計算するか

1. 設計軌道を 1 日分伝播します（`spec::daily_sampling`。刻みは軌道周期に従い、最大 10 分）。低軌道の地上トラックが地球を 1 周するのに十分な長さです。
2. 各サンプルで、位置を ECEF にして、McIlwain の L と比 B/B₀ を計算します（`sat_astro::radiation::belt_position`）。既定（`BeltConvention::Literature`）は文献の定義です。L は、地図が作られた時点の、その地図自身の磁場から、固定の双極子モーメント M = 0.311653 G·Rₑ³ を使って求め、B₀ = M/L³ とします。比較用の変種（`ModelDipoleLineMinimum`: L は磁場自身の双極子モーメントから求め、B₀ は磁力線上の |B| の最小値とする。IGRF パッケージの `SHELLG` と同じ）が検証用にありますが、解析は既定を使います。
3. 地図ごと（陽子と電子、太陽活動の極小期と極大期）、標準の格子のエネルギーごとに、そのエネルギー以上の積分全方向フラックス（cm⁻² s⁻¹）を地図から読みます。
   格子は、陽子が 0.1〜400 MeV、電子が 0.04〜7 MeV です（`proton_energies_mev`、`electron_energies_mev`）。
4. 出力は、地図とエネルギーごとの、時間平均のフラックス、ピークのフラックス、フラックスが 0 でない時間の割合、「フルエンス」（= 時間平均のフラックス × ミッション期間）です
   （設計にフェーズがないときに `orbit.total_dose` が使うミッション期間と同じです）。1 日分のサンプルがミッション全体を代表するものとし、ミッション中の軌道の変化は追いません。

L が見つからないサンプル（高緯度のように、磁力線が地球半径の 16 倍以内で閉じない場合）はモデルの外です。フラックス 0 として数え、`samples_without_l` に載せます。

| 解析 ID | `orbit.trapped_flux`（領域: 軌道の条件、種類: steady） |
|---|---|
| 必要なもの | 軌道（地球のみ）、ミッション期間、下のデータがインストールされていること（なければ、解析はインストール方法を示す入力不足になります） |
| 不要なもの | 部品のデータ |

## モデルと、それぞれが対にする磁場

地図は特定の地磁気の磁場で作った表なので、同じ磁場で読む必要があります。B と L はその磁場をモデル自身の元期のまま、永年変化を更新せずに使って計算します。

| 地図 | 粒子 | 太陽活動（元期） | 磁場 |
|---|---|---|---|
| AP8MIN（`ap8min`） | 陽子 | 極小期（1964） | Jensen & Cain（1960） |
| AP8MAX（`ap8max`） | 陽子 | 極大期（1970） | GSFC 12/66、1970 年へ外挿 |
| AE8MIN（`ae8min`） | 電子 | 極小期（1964） | Jensen & Cain（1960） |
| AE8MAX（`ae8max`） | 電子 | 極大期（1970） | Jensen & Cain（1960） |

これは SPENVIS と IRBEM が使う組み合わせです。NASA の readme は、地図には元期（1964 年と 1970 年）の磁場を使うべきだとしています。上の組み合わせは公開されている実装が採っているもので、NASA のサンプル出力もこれで作られています。

古い係数ファイルは `sat_astro::geomag::GaussModel` の Schmidt 準正規化の規約に変換します（`geomag::legacy`）。

- GSFC 12/66: すでに Schmidt で、符号も通常どおりです。t 年の係数は `g + ġ·Δt + ½·g̈·Δt²`（Δt = t − 1960）です。ファイルの 2 階微分が ½ 付きの意味かどうかは書かれていないので、これは仮定です。2 階微分の項は 1970 年の双極子で 30000 nT のうち約 3 nT なので、この選択で磁場が変わるのは約 1e-4 です。
- Jensen & Cain 1960: 符号は IGRF と逆（`g₁⁰ = +30411.2 nT`）で、ルジャンドル関数は Chapman–Bartels の「Gauss」関数です。変換は
  `g' = −g·(n−m)! / ((2n−1)!!·Sₙₘ)`、`Sₙₘ = √((2−δₘ₀)(n−m)!/(n+m)!)` です（h も同じ）。1960 年の IGRF-14 の係数と照合し、4 次までのすべての係数が 120 nT 以内で一致しました。
- どちらのファイルも、行の次数と位数は実際の値に 1 を足したものです。

## 限界

- モデルは静的です。太陽活動の極小期（1964）の地図と極大期（1970）の地図が 1 つずつあります。太陽周期の位相、磁気嵐による放射線帯の変動、磁場の永年変化はありません。
- 太陽高エネルギー粒子と銀河宇宙線は含みません。捕捉された陽子と電子だけです。
- AE-8 の電子モデルは外帯と最新の観測に対して不正確なことが知られています（後継は AE9/AP9）。AP-8 は太陽活動の極大期の南大西洋異常域で、低エネルギーの陽子フラックスを過大に見積もることが知られています。
  数値は概念設計向けです。
- 参照は NASA の TRARA1/TRARA2 を 1 ステップずつたどります（単精度、切り捨てたスケール済みの L と B/B₀、整数の FISTEP。`sat_astro::radiation::flux` を参照）。陽子帯の大気カットオフ付近（低い L で B/B₀ が大きい、つまり低軌道）では、フラックスが L と B/B₀ に非常に敏感なため、(L, B/B₀) の定義が数十パーセントの差になります（「検証」を参照）。
- 地球以外の天体のまわりの軌道は扱えません。

## 検証

参照は、NSSDC RADBELT プログラム（TRMFUN.FOR、1987。サブルーチン TRARA1 と TRARA2）の手順を、そのソースを読んで再実装したものです。そのコードも文章も、このリポジトリには入っていません。

- データセットの NASA のサンプル出力（`radbelt.log`）: テストが使う AE8MIN の積分フラックスの値はすべて（0 と非 0、地図の節点上と節点外、B/B₀ = 1 と > 1）、印字された 4 桁と一致します。相対差の最大は 4.98·10⁻⁴ で、4 桁の表の丸めです。（以前の近似の方式は、B/B₀ > 1 で L が節点の間にあるとき、最大 0.19 % ずれていました。）
- そのログの陽子の表は AP8MAX/AP8MIN ではなく、古い圧縮地図 AP8MAC のものです。地図が節点を共有するエネルギーと L ≤ 3 では AP8MAX が 2.4·10⁻⁴ で一致します。それ以外では地図が正当に異なるので、ログだけでは陽子の検証になりません。
- 公開されているエンドツーエンドの点（NASA `radbelt` の README: 経度 −45°、緯度 −30°、500 km、2021-03-01、AP8MAX、> 20 MeV、IGRF → 2642.50 cm⁻² s⁻¹）を、同じ参照とその日付の IGRF-14 で計算すると、文献の定義では L = 1.4310、B = 18997 nT、B₀ = 10635 nT、B/B₀ = 1.7863、フラックスは 3504（+33 %）、比較用の変種では L = 1.4133、B₀ = 10648 nT、B/B₀ = 1.7842、フラックスは 2636（−0.3 %）です。L = 1.4 付近のフラックスは L が 0.01 変わるごとに約 15 % 変わるので、L の定義のわずかな違いが目に見えます。README の値は、L と B₀ をその日付の磁場自身の双極子モーメントを使って IGRF のルーチンから取るツールのもので、これは比較用の変種と同じです。テストはこの一致を 1 % に固定しています。文献の定義は固定のモーメントを使うので、同じ点でも L が異なります。
- これらの比較は、データファイルがインストールされているとテストで実行されます（`crates/lib/astro/src/radiation/tests/nasa.rs` を参照）。ファイルはリポジトリにありません。

## データの出典

解析には、下に挙げるファイルが必要です。これらは、リポジトリにもプログラムにも入っていません。ユーザーごとのデータキャッシュ（DE440 天体暦と同じ場所）に、次のコマンドでインストールします。

```text
fune data fetch radiation                       # from the project's release (needs gh)
fune data fetch radiation --from <DIR>          # from a directory that holds the files (named as below)
fune data status                                # shows the state, the SHA-256 check and the attribution of each
```

GUI の設定ページは `POST /data/{id}/fetch` で取得します。`--from` は意図的に CLI だけのものです（HTTP はサーバー上のパスを受け取りません）。ID `radiation` はグループ全体を表します。

## 遮蔽の内側の線量（`orbit.trapped_dose`）

`orbit.trapped_dose` は、軌道平均した AP-8/AE-8 のスペクトルを、遮蔽の厚さに対するアルミニウム遮蔽の内側のシリコンの全電離線量率に換算します。
太陽活動の極小期（AP8MIN + AE8MIN）と極大期（AP8MAX + AE8MAX）について、捕捉陽子、捕捉電子、電子の制動放射、合計に分けて出力します。方法は SHIELDOSE-2 です
（S. M. Seltzer、NIST、NISTIR 5477、1994。最初の版は NBS Technical Note 1116、1980）。SPENVIS など同種のツールが使うモデルです。

| 解析 ID | `orbit.trapped_dose`（領域: 軌道の条件、種類: steady） |
|---|---|
| 必要なもの | 軌道（地球のみ）と上のデータファイル（足りないものは、`fune data fetch radiation` を示す入力不足になります） |
| 出力 | `cases[]`（太陽活動の極小期と極大期）。それぞれに表（アルミニウムの厚さ → 陽子、電子、制動放射、合計の線量率）があります。`used`（下のすべて）も出力します |
| 既定値（入力は任意で、出力にどれを使ったかが載ります） | 検出器はシリコン。幾何は中実のアルミニウム球の中心。陽子の核減衰なし。厚さ 0.1、0.2、0.5、1、1.5、2、3、4、5、7、10、15、20 mm |

### 方法

1. 軌道の位置は `orbit.trapped_flux` と同じです（軌道 1 日分。各サンプルの (L, B/B₀) は 1 回だけ求めて使い回します）。
2. 各地図について、積分フラックス `F(>E)` を、すべてのサンプルで対数等間隔の格子（10 倍あたり 25 点: 陽子は 0.1〜400 MeV、電子は 0.04〜7 MeV）上で読み、時間平均します（台形則）。
3. SHIELDOSE-2 が必要とする微分スペクトルは、隣り合う格子点の間の `j = (F_i − F_{i+1}) / (E_{i+1} − E_i)` とし、その幾何平均のエネルギーに置きます。隣り合うエネルギーの比は 1.10 なので、算術的な中点との差は 0.1 % 未満です。
   低エネルギー側の端では、ln j を ln E の直線で最初のエネルギーまで延ばします（そうしないと、最初の中点より下の半区間の粒子が失われます）。高エネルギー側の端では、F が 0 になるところで、差が正である連続した部分だけを使います（ln j には j > 0 が必要です）。F が 0 まで落ちる区間には、平均 `F_i / ΔE` を与えます。
   厳密なべき乗則のテストでは、差は 0.2 % 以内です。解析のテストに使う合成地図では、差分したスペクトルから計算した線量は、厳密な微分スペクトルの線量と 0.02 % 異なります。
4. SHIELDOSE-2（`sat_astro::radiation::shielding`）: ln j を ln E の自然 3 次スプラインで補間し（格子の半ステップより外へは外挿しません）、対数等間隔のエネルギー格子（最大 1001 節点）をシンプソン則で積分し（手順の `INTEG`）、線量のカーネル（CSDA 飛程でスケールした、深さに対する線量の表）を、
   陽子ではエネルギーと深さのスプラインで、電子と制動放射では ln T の線形で補間し（バージョン 2）、検出器とアルミニウムの比でアルミニウムをシリコンに換算し、単位の定数は 1.6021892·10⁻¹⁰ Gy g/MeV です。g/cm² の深さは厚さ × 2.70 g/cm³ です。
5. 中実の球の中心では、線量を板の曲線 `D(z)` から `D (1 − dlnD/dlnz)`（直進近似）として計算します。SHIELDOSE-2 と同じです。

### 幾何と係数 2

SHIELDOSE-2 の板の結果は、片側から入射する放射線のものです（平面を通る全方向フラックス φ は、通過の割合 φ/4 と平均の経路係数 2 を与えるので、深さ 0 の線量は φ/2 × 阻止能です）。
球は全方向から照射されます。深さ 0 の線量は φ × 阻止能です。SHIELDOSE-2 は球の値を板の曲線から導き、見出し *「1/2 dose at the centre of aluminium spheres」* の下に印字します。つまり板の規格化で、実際の線量の半分です。そのためカーネルは両方を返します。`GeometryDoses::sphere_half`（SHIELDOSE-2 が印字する値）と `sphere_centre()`（= 2 倍。実際の線量）です。解析の表は実際の線量を使います（`geometry = sphere_centre`）。
SHIELDOSE-2 の球の値をそのまま印字するツールと比べるときは、この解析の球の値を 2 で割るか、`semi_infinite_slab` を選んでください（その規格化は印字された板の値と等しくなります）。
カーネルのテスト（「検証」を参照）は、板の規格化（深さがほぼ 0 のとき φ/2 × 阻止能）と、印字された球の値がそこで板の値に等しいことを確かめています。実際の球の係数 2 は、幾何の議論（深さ 0 で φ × 阻止能）から導かれます。元の報告書（NISTIR 5477）からは読み取っていません。これを書いたときに利用できた資料では報告書を読めなかったので、読めるときに報告書で確かめてください。

### 核減衰のオプション

SHIELDOSE-2 の `INUC` のオプションはすべて実装しています。`none`（1、既定: 陽子は電離だけでエネルギーを失う。深いところでは保守的）、`local`（2: 陽子のフルエンスが核相互作用で減衰し、荷電した二次粒子のエネルギーは生じた場所で付与される）、
`local_with_neutrons`（3: オプション 2 に、中性子が運ぶエネルギーの粗い指数的な輸送を加える）です。オプション 2 と 3 は、オプション 1 よりテストが少なく、オプション 2 は深いところでオプション 1 より大きい線量を与えることがあります。

### 限界

- 捕捉陽子、捕捉電子、制動放射だけです。太陽高エネルギー粒子、銀河宇宙線、SHIELDOSE-2 自身の扱いを超える、宇宙機の構造で生じる粒子はありません。
- 単純な幾何（球の中心と板）のアルミニウム遮蔽です。部品のまわりの実際の質量分布は扱いません。球の式は直進近似で、散乱が効くところでは厳密ではありません。
- 上の AP-8/AE-8 の限界が当てはまります（静的なモデルで、外帯の変動はありません）。太陽活動の極小期と極大期の地図は、定義されている磁場も異なります。
- スペクトルは 1 日分の軌道平均のスペクトルです。線量率はミッション全体の平均で、軌道の変化は追いません。

### `orbit.total_dose` との関係

`orbit.total_dose` のレッグに表（`dose_rate_by_shielding`）がない、かつ `fune data fetch radiation` のデータがインストールされているとき、そのレッグの環境は、そのレッグの軌道に対する `orbit.trapped_dose` で計算します（独自の `[orbit]` を持つフェーズは、独自の計算になります）。各厚さで、表は太陽活動の極小期と極大期の合計の大きいほうを取ります（低軌道では、極小期は陽子、極大期は電子が支配的で、どちらの条件が常に悪いとは限らないため、包絡が保守的な選択です）。既定の幾何（中実のアルミニウム球の中心）とシリコンを使います。
ユーザーの表は常に優先されます。各レッグの出どころは出力にあり（`legs[].environment_source`: `user_table` か `computed_trapped`）、計算した表には警告のチェック `environment_source` が付きます。捕捉粒子だけを含むので、合計は下限です。
期間のないレッグは計算しません。計算が不可能なとき（ほかの中心天体、データなし）は、これまでどおりレッグに表がなく、除外されます。データファイルがなければ、動作はこれまでとまったく同じで、入力不足の理由にも `fune data fetch radiation` が出ます。

### 検証（SHIELDOSE-2 の部分）

- 読み込みは、ソースの DATA 文のすべてを、独立したスクリプトで変換後のファイルと比べました（配列の順序: 最後の添字が最速。検出器と、電子と制動放射の配列の 2 つの `m` の表）。テストは代表的な値を固定し、リーダーは誤った個数、名前、次元、`end` の欠落、数値でないものを拒否します。
- 深さがほぼ 0 の単一エネルギーでは（カーネルの単位フルエンスあたりの線量を、同じデータの飛程表 `S = dE/dR`、線量 = φ/2 × S × 1.6021892·10⁻¹⁰ と比較）: 0.1 MeV から 1 GeV までのエネルギーで 0.7 % 以内に一致します。100 MeV で、表の `S` は 5.65 MeV cm²/g で、アルミニウム中の陽子の文献値は約 5.7 です（ICRU Report 49、NIST PSTAR）。99〜101 MeV の帯の表面線量は φ/2 × S より 0.7 % 大きくなります。
- 飛程については、CSDA 飛程が遮蔽の深さより短い陽子は、板と球の線量がちょうど 0 になります（10 MeV の陽子、飛程 ≈ 0.17 g/cm²、1 g/cm² の後ろ）。電子は厚い遮蔽で止まり、制動放射が残ります。
- 板から球への換算では、べき乗則の板の曲線 `D = A z^−p` の球の値は `D (1 + p)` です（1e-12 まで厳密）。ln z の 2 次曲線では、格子内で解析的な導関数と 0.1 % 以内で一致します。
- スペクトルの積分（NBS TN 1116 付録 C のサンプル、指数関数的な太陽陽子のスペクトル E₀ = 26.5 MeV、C = 2.45·10¹⁰、範囲 2〜1000 MeV）: 積分スペクトルは、201、501、1001 点のどれでも 2.2719·10¹⁰（印字は 2.2719E+10）で、平均エネルギーは 28.5000 MeV です。報告書は 28.50006 を印字しています。この指数関数の厳密な値は 28.5 で、印字された 28.50006 との相対差は 2·10⁻⁶ です（サンプルの格子の大きさはここでは分かりません。同じシンプソン則は、16〜30 点で 28.4965 から 28.5001 の間になります）。
- 解析では、合成の陽子地図（フラックスが閉じた形で分かる）の最小の深さの球の線量が、独立に計算した ∫ j S r dE × 1.6021892·10⁻¹⁰ Gy g/MeV の 0.11 % 以内です（r = データのシリコンとアルミニウムの比）。
